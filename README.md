# Space Invaders

Este repositório contém uma implementação do lendário jogo Space Invaders, desenvolvida em Python utilizando a biblioteca PPlay (uma abstração simplificada construída sobre o Pygame).

> 🚧 **Em desenvolvimento.** O projeto é feito como estudo, em pequenas etapas. O andamento está nas [Issues](../../issues).

## O que o jogo terá

- Nave que se move e atira, contra tropas de aliens de 3 tipos
- Aliens que atiram de volta, escudos destrutíveis e uma nave bônus (UFO)
- Vidas com corações, pontuação e ondas cada vez mais difíceis
- Menu, pausa, game over e tela de novo recorde
- Escolha de nome e avatar do jogador, e ranking salvo em arquivo
- Sons, músicas e efeitos visuais originais

## Tecnologias

- Python 3
- PPlay, sobre o Pygame (a PPlay já está incluída na pasta `PPlay/`)

## Como rodar

_A preencher quando o jogo tiver o primeiro arquivo executável._

## Controles

_A preencher conforme os controles forem implementados._
